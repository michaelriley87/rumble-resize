# Rumble Resize

Rumble Resize is a web browser extension designed to enhance your viewing experience on Rumble by making the Theatre Mode fill the entire browser window. Whether you
prefer to watch with or without the live chat, Rumble Resize ensures a seamless, immersive viewing experience. Additionally, you can still scroll down the page 
without any interruptions. Enjoy Rumble videos in full-screen mode like never before!

## Functionality
- **Optional Automatic Theatre Mode:** The toolbar popup can make Rumble enter its native theatre mode when a video begins playing or autoplays. This is on by default for everyone.
- **State Synchronization:** Derives the layout from Rumble's actual theatre-mode state and the browser's fullscreen state instead of tracking button clicks.
- **Dynamic Player Support:** Reacts when Rumble creates or replaces player controls without polling or timeouts.
- **Flexible Viewing:** Works with chat and the sidebar menu on or off while preserving page scrolling for video details and comments.

## Development

Run the dependency-free state tests with:
